PRD 3: Target Classifier (Threat Identification)
1. Objective
Develop, train, and export a highly compressed Spiking Convolutional Neural Network (S-CNN). The model must ingest the anomaly bounding boxes generated by the Autoencoder and output precise tactical threat classifications utilizing rate-coded neuromorphic logic.
2. Data Synthesis & Preprocessing
⚬ Source Data: Datasets of tightly cropped, isolated military assets and vehicles.
⚬ Target Classes: [0: Infantry, 1: Armored Vehicle, 2: Tactical Truck, 3: RF Signature, 4: False Positive / Environmental Noise].
⚬ Augmentation Pipeline: Apply extreme rotations, partial occlusion masks, and low-light degradation to simulate varied aerial engagement angles and battlefield obstructions.
⚬ Input Scaling: Resize all incoming bounding box tensors to a fixed, lightweight spatial dimension (e.g., 64 \times 64) to maintain a minimal memory footprint during edge inference.
3. Model Architecture
Component	Specification
Topology	Lightweight Spiking ConvNet (e.g., an SNN adaptation of MobileNetV3).
Neuron Dynamics	Leaky Integrate-and-Fire (LIF) neurons utilizing snnTorch.
Optimization Mechanics	Surrogate Gradients (e.g., Fast Sigmoid) to enable backpropagation of binary spikes.
Readout Mechanism	Rate-coding: The classification is determined by the output neuron that fires the highest count of spikes across the full simulation window (T).
Confidence Metric	Temperature-scaled output converting raw spike rates into strict percentage probabilities.
Loss Function	Cross-Entropy Loss.
4. Export & Hardware Handoff
⚬ Format: ONNX format.
⚬ Temporal Unrolling: Static unrolling of the temporal simulation graph to ensure compatibility with standard C++ ONNX Runtime edge execution.
⚬ Deliverables: The finalized .onnx model weights and a strictly mapped JSON dictionary translating the numerical output classes (0-4) into plain-text tactical strings for immediate rendering on the Python UI dashboard.
